# Project Flow

Project Flow is a simple SDLC-based project management web application built as part of the Utpatti Finishing School assignment.  
The project demonstrates basic full-stack development using the MERN stack and shows how tasks move through different stages of the Software Development Life Cycle.

## Tech Stack
- Frontend: React, CSS
- Backend: Node.js, Express
- Database: MongoDB

## Features
- Add and manage users
- Create tasks and optionally assign them to users
- View tasks in SDLC stages: Backlog, In Progress, Done
- Move tasks from one stage to another
- Delete users and tasks

## How to Run the Project

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm start

The frontend runs on `http://localhost:3000`  
The backend runs on `http://localhost:5000`

## Notes
- MongoDB should be running locally on the system
- This project focuses on core functionality and clean structure
